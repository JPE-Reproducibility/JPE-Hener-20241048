                      README

                      Overview
                      The code in this replication package constructs the analysis ffle from source
                      ffles provided by the West Midlands Police Force. One code ffle for STATA
                      runs all of the code to generate the estimation data and to produce the 3 main
                      ffgures, 6 main tables, 2 appendix ffgures, and 8 appendix tables in the paper.
                      Moreover, auxiliary results mentioned in the paper are produced here as well.
                      The replicator should expect the code to run for about 22 hours.

                      Data Availability and Provenance Statements
                      The data used in this article consist of administrative records provided by
                      West Midlands Police (WMP) under a formal Information Sharing Agreement
                      (ISA) between West Midlands Police, the University of Birmingham, and the ifo
                      Institute, Munich (Version 3.0, May 2018).
                      The authors are secondary data users; the data were generated and held by
                      West Midlands Police and accessed under the terms of the ISA. The data are
                      stored at the ifo Institute, Munich (Poschingerstraße 5, 81679 München) on
                      a secure, password-protected server with restricted access. Security measures
                      include device-level encryption and continuous IT-breach monitoring by the ifo
                      IT team. The data cannot be redistributed as part of a replication package.
                      Access is restricted to parties named in the ISA, and personal data may not be
                      published in identiffable form unless the individuals concerned have provided
                      explicit consent.
                      Researchers wishing to replicate this work should contact the WMP Evidence
                      Based Practice Team (our contact at the time of signing the ISA was Jenny
                      Richards; evidencebasedpractice@west-midlands.pnn.police.uk; 0845 113 5000
                      Ext 801) to inquire about the conditions under which a new data-sharing
                      agreement may be established. Any such access will be subject to WMP’s data
                      governance procedures, ethical approval, and the execution of a new ISA.
                      Auxiliary data used in this study (for two ffgures in the main text) comes from
                      the British Crime Survey. To replicate the numbers, download the replication
                      package (https://onlinelibrary.wiley.com/doi/abs/10.1111/ecoj.12246), obtain
                      survey access, run the code in "BCS2005_EJ.do" and "Dataset_Final_EJ.do",
                      and place "Analysis_Final_EJ.dta" in the Rawdata folder.

                                                  4                      Description of programs/code
                          All code is being controlled by master.do. Running it prompts
                          01_build_sample.do to, which builds the estimation dataset from
                          the raw data ffles. Then, 02_analysis.do is started, which produces
                          all ffgures, tables, and other exhibits in the paper.
                        •The ffleprograms/code/01_build_sample.dowill extract and reformat
                          all datasets referenced above. Intermediate data ffles are save in Tempdata
                          folder and the ffnal estimation data set is saved in Estdata folder.
                        •The ffleprograms/code/02_analysis.dogenerates all tables, ffgures, and
                          other mentions of results in the main body and appendix of the article
                          and are saved in the Results folder. Output ffles are called corresponding
                          names also found in the manuscript.
                        •The programprograms/code/0_install_dependencies.domakes sure
                          and installs if necessary all needed dependencies for stata.
                        •The programprograms/master.dostarts all programs in order.

                      Instructions to Replicators
                        •Store the ffles and folders contained in the replication package in a
                          yourfolder/replication/and place the raw data ffles described above
                          inyourfolder/Rawdata/.
                        •Editreplication/master.doto adjust the default path
                        •Runreplication/master.doto produce all intermediate data and all
                          results.

                      Details
                        •replication/code/0_install_dependencies.do:
                            –Installs all required Stata packages if they are not already available.
                        •replication/code/01_build_sample.do:
                            –Reads the raw data ffles from theRawdatafolder.
                            –Cleans, merges, and reformats the data to construct the estimation
                              dataset.
                            –Intermediate datasets are stored in theTempdatafolder and the ffnal
                              estimation dataset is saved in theEstdatafolder.
                        •replication/code/02_analysis.do:
                            –Produces all tables and ffgures reported in the main text and appendix.
                            –Output is saved in theResultsfolder using fflenames corresponding
                              to the manuscript.
                            –This program should be run only after01_build_sample.dohas
                              completed successfully.
                        •replication/master.do:
                            –Creates all required output directories.
                            –Executes all programs in the correct order:0_install_dependencies.do,
                              01_build_sample.do, and02_analysis.do.
